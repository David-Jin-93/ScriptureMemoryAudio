# ScriptureMemory Audio

성경암송 앱에서 선택 다운로드하여 사용하는 사전 생성 음성 파일입니다. 앱 소스는 별도 비공개 저장소에서 관리합니다.

- 5확신, 60구절, 108구절, 180구절, DEP242
- 남성: Google Chirp 3 HD Charon / 여성: Google Chirp 3 HD Kore
- 총 595개 암송 항목, 남녀 음성 1,190개
- 제목 → 성경 장절 → 본문 순서
- 각 분류와 음성별 ZIP 10개

`audio-v1` 릴리스에서 필요한 ZIP을 내려받을 수 있습니다. `download-packs.json`과 `SHA256SUMS.txt`에 파일 크기와 SHA-256이 기록되어 있습니다. 앱은 다운로드와 압축 해제 후 파일 검증을 완료한 음성만 재생합니다.

다운로드한 MP3는 기기에서 반복 재생하므로 재생할 때마다 TTS를 새로 생성하지 않습니다. 음성 생성 기술명과 분류는 호환성 안내를 위한 정보이며 Google의 공식 앱이나 공식 배포 자료를 의미하지 않습니다.
